PROJECT PHILOSOPHY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Lipi is not a Hospital Management System.

It is not a cloud service.

It is not another note-taking application.

Lipi is a clinical workspace.

It exists to preserve the natural workflow of doctors while providing the reliability, organization, and longevity of digital records.

Technology should adapt to the doctor.

The doctor should never be forced to adapt to technology.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
CORE PRINCIPLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Handwriting First

Handwriting is the primary method of interaction.
Typing is supported where useful, but never required.

Offline First

The application should function completely without an internet connection.

Local First

Patient data belongs to the doctor.

No mandatory cloud.

No vendor lock-in.

Reliability Over Features

A feature that cannot be trusted has no value.

Simple Over Clever

Predictability is preferred over unnecessary complexity.

Long-Term Thinking

Every architectural decision should be evaluated on whether it remains maintainable years into the future.

Open Source

Knowledge grows through collaboration.

Clinical Workflow First

The application should respect how experienced doctors already work instead of forcing a completely new workflow.
